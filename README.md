# Caixa Eletrônico

Projeto de um sistema de caixa eletrônico desenvolvido em C.

## Funcionalidades

- Cadastro de contas
- Consulta de contas
- Depósito
- Saque
- Listagem de contas
- Desativação e reativação de contas

## Tecnologias

- C
- TAD
- Struct
- Arquivo binário

## Arquivos

- `main.c` — menu principal
- `conta.c` — funções do sistema
- `conta.h` — estrutura e funções

## Como executar

```bash
gcc main.c conta.c -o caixa_eletronico
.\caixa_eletronico.exe
